What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on websites.

HTML is not technically a programming language. Instead, it tells the browser what different pieces of content are.

Think of a website like a house

  • HTML = structure
  • CSS = appearance
  • JavaScript = behavior
